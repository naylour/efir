# Efir

> Tune in. Stay in flow.

**Efir** is a minimal, keyboard-first internet radio built for the terminal.

Choose a station for work, reading, rest, or anything in between — then let Efir fade into the background.

## Status

Efir is in early development. The interface, playback model, and station catalog are still taking shape.

## Direction

* Curated internet radio stations
* Browsing by genre and activity
* Fast, keyboard-driven navigation
* Essential playback controls
* A quiet, distraction-free terminal interface
* Lightweight background playback

## Philosophy

Efir should be quick to open, easy to control, and invisible when it is no longer needed.

No feeds. No recommendations. No visual noise.

Just your terminal and the right sound for the moment.

## Development

cargo run
